# 은행 열매 민원 데이터 수집 (디지털 미디어 파이널)

국민권익위원회 민원빅데이터 API(2022, 키워드 트렌드)로 전국 136개 지역의
'은행 열매' 민원 일별 건수(2021~2025년 8/15~11/30)를 GitHub Actions에서 받는다.

## 파일
- `regions.csv` : 지역과 행정기관코드 (행정표준코드관리시스템 기준)
  - 강원(2023년~)·전북(2024년~)은 특별자치도 출범으로 코드가 바뀌어 연도별로 옛코드/새코드를 쓴다.
  - 부천 구는 2024년에 다시 생겨 2024년부터만 조회한다.
  - 광주 구와 전남 시는 2026년 통합 전 코드를 쓴다.
- `fetch.py` : 조회 스크립트
- `.github/workflows/minwon.yml` : 자동 실행 설정 (한국시간 01:07, 13:07)
- `data/민원_은행열매_일별.csv` : **최종 결과** (그룹, 지역, 기관코드, 연도, 날짜, 건수). 실행할 때마다 갱신
- `data/raw/` : 원본 JSON (지역_연도.json)
- `data/log.txt` : 실행 기록

## 설정
1. Settings → Secrets and variables → Actions → New repository secret
   - Name: `MINWON_KEYS`
   - Secret: 공공데이터포털 Decoding 인증키. 팀원 키가 여러 개면 한 줄에 하나씩.
2. Actions 탭 → "민원 데이터 받기" → Run workflow → mode `test` → 실행 (약 16분)
3. 시험이 잘 되면 자동 실행이 하루 2번 돈다. 바로 시작하려면 mode `run`으로 한 번 실행.

## 제한
- 같은 키는 호출 사이 약 5분 간격이 필요하고, 하루 100회까지.
- 전체 671회: 키 1개면 약 7일, 키 6개면 약 하루 남짓.

출처: 국민권익위원회 민원빅데이터 분석정보 API (공공누리 제2유형)
